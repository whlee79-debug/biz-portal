> 웹 대시보드([biz-portal](http://34.83.67.147/dashboard/)) 원본 데이터를 여기서 관리합니다.
> 표를 수정한 뒤 **동기화**를 실행하면 검증을 거쳐 웹에 반영됩니다.

> 모든 데이터는 **가상의 데모 데이터**입니다.

## 편집 규칙

- **표의 열(헤더)은 바꾸지 마세요.** 동기화가 열 이름으로 데이터를 인식합니다.
- 월이 넘어가면 각 월별 표 맨 아래에 새 행을 추가하세요 — 웹 차트가 자동으로 늘어납니다.
- 새 달에 함께 고칠 것: [[경영 요약]] frontmatter의 `기준월`·`보고월`, 의사결정 안건, [[재무]] 현금흐름 예측.
- 숫자는 단위 없이 (예: `545`, `17.8`). 빈 값은 `—`.
- 동기화가 정합성(원가 합계, 부서 인원 대사, m당 원가 등)을 검증하고, 어긋나면 어디를 고칠지 알려줍니다.

## 📈 차트 자동 연동

- 구현: `Dataview`가 표를 읽어 → `Charts` 플러그인으로 그림 (공용 스크립트 `_scripts/chart/view.js`)
- 차트가 안 보이면 **설정 → Dataview → "Enable JavaScript Queries"** 를 켜주세요.
